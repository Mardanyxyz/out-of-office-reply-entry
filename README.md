# Funniest One-Line Out-of-Office Reply

A v1 entry for the make.fun bounty [Funniest One-Line Out-of-Office Reply](https://make.fun/c/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8): a small Node program (`main.ts`) that deterministically writes one funny out-of-office email auto-reply — a single line, 1 to 160 characters — to `/output/entry.txt`.
